# ygg-control

Панель управления [Yggdrasil](https://yggdrasil-network.github.io/) для Windows: всё, что умеет Yggdrasil, в одном окне - без командной строки.

Пара к [ygg-watchdog](https://github.com/Yozmor/ygg-watchdog): сторож сам следит за пирами, а здесь - ручное управление. Если сторож установлен, панель показывает его состояние внизу и открывает его окно клавишей **W**.

## Что умеет

| Экран | Что там |
|---|---|
| Статус узла | адрес, подсеть, ключ, версия, TUN, служба, пиры/глубина/пути/сессии, график трафика за час |
| Пиры | задержка, трафик, время, ошибки; добавить пир с проверкой (DNS, порт, рукопожатие), убрать, записать в конфиг, пинг всех |
| История задержек | задержка каждого пира за 6 / 24 / 48 часов по history.log watchdog: график с осью, которая подстраивается под значения, полоса состояний, галочки у пиров (показать / скрыть линию), процент времени на связи, средняя / мин / макс |
| Дерево маршрутов | карта сети от тебя до корня: масштаб, перетаскивание, путь до узла, пинг, запрос узла |
| Сессии | с кем ты сейчас общаешься, трафик по каждой сессии |
| Таблица путей | маршруты по портам, через какого пира, сортировка |
| Устройства | адресная книга: имя и адрес Yggdrasil, пинг, пинг всех, копирование адреса; где устройство сейчас видно. Имена из книги показываются в дереве, сессиях и путях. Хранится в `addressbook.txt` рядом с панелью, устройства из watchdog подтягиваются сами |
| Удалённый узел | NodeInfo, сведения, пиры и дерево другого узла по его ключу |
| Интерфейсы | TUN-адаптер, автопоиск соседей (multicast), входящие (Listen) |
| Служба | старт, стоп, перезапуск, перезапуск через 15 с, тип запуска, пути; проверка обновлений Yggdrasil на GitHub и установка новой версии |
| Лог | фильтр по уровню, поиск, автопрокрутка |
| Конфиг | правка всех полей, кроме закрытого ключа; проверка самим yggdrasil перед записью, копия старого |
| Ключ узла | публичный ключ, экспорт закрытого в PEM, новый ключ (новый адрес) |
| Все команды | любая команда yggdrasilctl с параметрами, ответ в JSON |
| Watchdog | состояние ygg-watchdog, разбор «почему нет связи», последние события, открыть его окно, проверить сейчас, включить / выключить автопроверку |

Управление: команды слева - мышью или стрелками **↑ ↓**. **Tab / Shift+Tab** переводит фокус: список команд → поля → списки → таблица экрана и обратно; стрелки работают там, где фокус (рамка). **W** - окно сторожа, **T** - проверка сторожем, **Esc** - назад / к списку команд / свернуть.

## Безопасность

- Закрытый ключ панель **не показывает**. Экспорт - только в файл, который ты выбрал.
- Перед записью конфиг проверяет сам `yggdrasil -normaliseconf`; старый сохраняется рядом как `yggdrasil.conf.bak-ДАТА`.
- Конфиг записывается в JSON - комментарии из файла пропадут (Yggdrasil читает JSON так же, как HJSON).
- Опасные действия (остановка службы, удаление пира, новый ключ) спрашивают подтверждение.
- Файрвол и другие программы панель не трогает.

## Установка

1. Нужен установленный Yggdrasil для Windows (служба «Yggdrasil»).
2. Скачай `ygg_control.exe` и запусти - Windows попросит права администратора (нужны для службы, конфига в `C:\ProgramData\Yggdrasil` и `yggdrasilctl`).

Сторожа панель находит сама: он при каждом запуске записывает свой путь в `HKLM\SOFTWARE\Yozmor\ygg-watchdog`. Если не нашла - внизу есть «указать ygg_watchdog.exe…».

Пути панель берёт из настроек службы (`-useconffile`, `-logto`), адрес управления - из `AdminListen` в конфиге.

## Сборка

Запусти `build.bat` - соберёт `ygg_control.exe` (MinGW-w64 g++ или Visual Studio) и откроет панель. Сторонних библиотек нет: окно рисуется на Direct2D.

```
src/ygg_control.cpp   окно и экраны
src/core.h            Yggdrasil: пути, yggdrasilctl, конфиг, фоновый сбор данных
src/util.h            процессы, пинг, DNS, порт, служба Windows
src/ui.h              мини-библиотека отрисовки (общая с ygg-watchdog)
src/json_lite.h       JSON
src/app.rc            иконка и фон
```
