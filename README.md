<h1 align="center">ygg-control</h1>

Панель управления [Yggdrasil](https://yggdrasil-network.github.io/): всё, что умеет Yggdrasil, собрано в одном месте, команды `yggdrasilctl` наизусть знать не нужно. Пиры, дерево маршрутов, сессии, служба, конфиг, ключ и лог видно и правится с клавиатуры, а на Windows и мышью.

- **Windows** — графическое окно (Direct2D, без браузерного движка), лёгкое по памяти и видеокарте.
- **Linux** — полноэкранный интерфейс в терминале. *В разработке.*

Пара к [ygg-watchdog](https://github.com/Yozmor/ygg-watchdog): сторож сам следит за связью и чинит её, а панель отвечает за ручное управление. Если сторож установлен, панель показывает его состояние и открывает его клавишей **W**.

## Быстрый старт

**Windows.** Скачай [`windows/ygg_control.exe`](windows/ygg_control.exe) и запусти. Windows попросит права администратора — соглашайся, они нужны для службы, конфига и `yggdrasilctl`. Нужен только установленный Yggdrasil для Windows. Подробно: [windows/README_WINDOWS.md](windows/README_WINDOWS.md)

**Linux.** Пока в разработке, описание появится в [linux/README_LINUX.md](linux/README_LINUX.md).

## Что умеет

| Экран | Что там |
|---|---|
| Статус узла | адрес, подсеть, ключ, версия, TUN, служба; пиры, глубина в дереве, пути и сессии; график трафика за час |
| Пиры | задержка, трафик, время подключения, ошибки. Можно добавить пир с проверкой (DNS, порт, рукопожатие), убрать, записать в конфиг, пингануть все |
| История задержек | задержка каждого пира за 6 / 24 / 48 часов по истории ygg-watchdog: график, полоса состояний, процент времени на связи, средняя / мин / макс |
| Дерево маршрутов | карта сети от тебя до корня: масштаб, путь до узла, пинг, запрос сведений об узле |
| Сессии | с кем ты сейчас общаешься и трафик по каждой сессии |
| Таблица путей | маршруты по портам, через какого пира идут, сортировка |
| Устройства | адресная книга: имя и адрес Yggdrasil, пинг, копирование адреса, где устройство сейчас видно. Имена из книги показываются в дереве, сессиях и путях; устройства из ygg-watchdog подтягиваются сами |
| Удалённый узел | NodeInfo, сведения, пиры и дерево другого узла по его ключу |
| Интерфейсы | TUN-адаптер, автопоиск соседей (multicast), входящие подключения (Listen) |
| Служба | запуск, остановка, перезапуск сразу или через 15 с, тип запуска, пути; обновления Yggdrasil и самой панели |
| Лог | фильтр по уровню, поиск, автопрокрутка |
| Конфиг | правка всех полей, кроме закрытого ключа; проверка самим Yggdrasil перед записью, копия старого файла |
| Ключ узла | публичный ключ, экспорт закрытого в PEM, новый ключ (а с ним новый адрес) |
| Все команды | любая команда `yggdrasilctl` с параметрами, ответ в JSON |
| Watchdog | состояние ygg-watchdog, разбор «почему нет связи», последние события, открыть сторожа, проверить сейчас |

Таблица описывает Windows-версию. Что из этого будет в Linux-версии, допишу, когда она выйдет.

## Обновления

Релизов нет: всё лежит прямо в этом репозитории. Панель сама сверяет свою версию с репозиторием и обновляется по кнопке: скачанный файл проверяется по отпечатку git и самопроверкой новой версии, а старая версия сохраняется и возвращается сама, если новая не запустилась. Подробно — в описании для своей системы.

## Безопасность

- Закрытый ключ панель **не показывает**. Экспорт возможен только в файл, который ты выбрал сам.
- Перед записью конфиг проверяет сам Yggdrasil (`-normaliseconf`). Старый файл сохраняется рядом как `yggdrasil.conf.bak-ДАТА`, а новый записывается целиком или не записывается вовсе.
- Опасные действия (остановка службы, удаление пира, новый ключ, обновление) спрашивают подтверждение.
- Фаервол и другие программы панель не трогает.
