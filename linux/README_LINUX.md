# ygg-control для Linux

Панель управления Yggdrasil прямо в терминале: полноэкранное окно, управление с клавиатуры. Одна программа на C++, нужен только OpenSSL (есть в любой Ubuntu). Работает и по SSH.

Общее описание и Windows-версия — в [README.md](../README.md).

## Установка

Нужны установленный Yggdrasil (служба `yggdrasil`) и, для сборки, `g++` и `libssl-dev`. Скачивается только папка `linux` — Windows-часть не загружается:

```bash
sudo apt install g++ libssl-dev git
git clone --depth 1 --filter=blob:none --sparse https://github.com/Yozmor/ygg-control.git /tmp/ygc-src
git -C /tmp/ygc-src sparse-checkout set linux
mkdir -p ~/ygg-control
cp -r /tmp/ygc-src/linux/. ~/ygg-control/
rm -rf /tmp/ygc-src
cd ~/ygg-control
chmod +x build.sh install.sh tests/run_tests.sh ygg-control 2>/dev/null   # разрешить запуск (из Windows-коммита оно теряется)
./build.sh              # можно пропустить: готовая ygg-control уже лежит в папке
sudo ./install.sh
```

`install.sh` проверяет программу и добавляет команды `yggdrasil` и `ygg-control` — обе открывают панель. Сама панель живёт в домашней папке, в `~/ygg-control`: там же её адресная книга `addressbook.txt`. В системе появляются только ссылки в `/usr/local/bin`.

**Удаление:** `sudo ./install.sh --remove` (убирает обе команды, файлы остаются).

## Запуск

```bash
yggdrasil
```

(или `ygg-control` — то же самое). Попросит пароль sudo: `yggdrasilctl`, конфиг и `systemctl` требуют root. Нужен терминал хотя бы 80×24.

**Команда `yggdrasil` и сам Yggdrasil.** Так же называется программа самого Yggdrasil (`/usr/bin/yggdrasil`). Панель различает вызовы: `yggdrasil` **без аргументов** открывает панель, а **с аргументами** (`yggdrasil -genconf`, `yggdrasil -version`, `yggdrasil -useconffile …`) передаёт их настоящему Yggdrasil — он и служба работают как раньше (systemd запускает службу по полному пути). Если в `/usr/local/bin/yggdrasil` уже лежит сам Yggdrasil (ручная установка), `install.sh` его не трогает, и панель открывается командой `ygg-control`. Если сразу после установки `yggdrasil` в открытом терминале ведёт себя по-старому — выполни `hash -r` или открой новое окно.

## Главное меню

| Клавиша | Экран |
|---|---|
| **1** | статус узла: адрес, подсеть, ключ, версия, TUN, служба; пиры, глубина, пути, сессии; трафик за час |
| **2** | пиры: задержка, трафик, время на связи, ошибки. **a** — добавить с проверкой (DNS, порт, рукопожатие), **d** — убрать (и из конфига), **w** — записать в конфиг, **p** — пинг всех |
| **3** | история задержек за 6 / 24 / 48 ч из `history.log` сторожа: график выбранного пира, полоса связи и режима, % на связи, ср/мин/макс |
| **4** | дерево маршрутов: путь от корня до тебя и твои потомки, остальные ветки свёрнуты (**Enter** раскрывает), **/** — найти по адресу или имени |
| **5** | сессии: с кем ты общаешься, трафик и мини-график скорости |
| **6** | таблица путей: маршрут по портам, через какого пира, сортировка **Tab** |
| **7** | устройства: адресная книга (имя и адрес), пинг, где устройство сейчас видно; устройства сторожа подтягиваются сами |
| **8** | удалённый узел: NodeInfo, сведения, пиры и дерево другого узла по ключу |
| **9** | интерфейсы: TUN-адаптер и его адреса, автопоиск соседей (multicast), Listen |
| **s** | служба: перезапуск сразу или через 15 с, остановка, запуск, автозапуск, память и процессор |
| **l** | лог `journalctl -u yggdrasil`: уровень (**Tab**), поиск (**/**), листание, слежение за новыми (**f**) |
| **c** | конфиг: все поля, кроме закрытого ключа; проверка самим Yggdrasil перед записью, копия старого файла |
| **k** | ключ узла: публичный ключ, экспорт закрытого в PEM, новый ключ (а с ним новый адрес) |
| **a** | все команды `yggdrasilctl` с параметрами, ответ в JSON |
| **u** | обновления панели и Yggdrasil |
| **W** / **T** / **V** | сторож пиров: открыть его окно, проверить сейчас, состояние и журнал событий |

Везде: **↑ ↓** — выбор, **Enter** — открыть или изменить, **Esc** — назад, **q** — выход. В меню **/** — поиск по пунктам. Буквы работают и в русской раскладке. На экранах дерева, сессий и путей: **p** — пинг, **i** — сведения об узле, **c** — копировать адрес, **b** — в устройства.

**Копирование** идёт через OSC 52 — так умеет большинство терминалов (GNOME Terminal, Konsole, kitty, Alacritty, Windows Terminal), и через SSH тоже. Если терминал не умеет, адрес виден в строке внизу — выдели мышью.

## Сторож пиров

[ygg-watchdog](https://github.com/Yozmor/ygg-watchdog) — отдельная программа: сам ищет замену упавшим пирам и шлёт уведомления. Панель находит его по `/etc/yozmor/watchdog_path` (его пишет установка сторожа) или по команде `ygg-watchdog` и показывает его состояние внизу главного меню. Без сторожа панель работает, только экран «История задержек» будет пустым — её пишет сторож.

## Обновления

Релизов нет: всё лежит в репозитории. При запуске панель тихо сверяет `PANEL_VERSION` в `linux/src/panel/version.h` и показывает «1 новое» у пункта **[u]**. Установка — **u** → **i** (или `sudo ygg-control update`):

1. скачивается `linux/ygg-control` и сверяется его git-отпечаток с репозиторием;
2. новая версия запускается с `--selftest` и должна назвать ту версию, что в исходнике;
3. работающий файл заменяется переименованием, старый остаётся как `ygg-control.backup`; если на месте новая не прошла самопроверку — старая возвращается. Панель перезапускается сама.

Там же — новая версия Yggdrasil: **y** скачивает `.deb` из релиза и ставит через `apt` (конфиг и ключ не трогаются).

### Выпуск новой версии (для автора)

1. Подними `PANEL_VERSION` в `linux/src/panel/version.h`.
2. Собери: `./build.sh`, проверь: `./tests/run_tests.sh`.
3. Закоммить вместе `version.h` и собранный `linux/ygg-control`.

Чтобы разрешение на запуск хранилось в репозитории и `chmod` после клонирования был не нужен, один раз (можно на Windows, в Git Bash):

```bash
git update-index --chmod=+x linux/build.sh linux/install.sh linux/tests/run_tests.sh linux/ygg-control
git commit -m "linux: разрешение на запуск"
```

## Файлы

| Файл | Зачем |
|---|---|
| `ygg-control` | программа (собирается `build.sh`) |
| `src/common/` | общее со сторожем ygg-watchdog: строки, файлы, JSON, HTTPS, yggdrasilctl, окно в терминале |
| `src/panel/` | панель: данные (`data.h`), каркас и меню (`app.cpp`), экраны (`screens1-3.cpp`), версия |
| `tests/` | `tests.cpp` и `run_tests.sh` — проверки без сети и без Yggdrasil |
| `build.sh`, `install.sh` | сборка и установка |
| `addressbook.txt` | адресная книга: имя<TAB>адрес (появится после первой записи) |
