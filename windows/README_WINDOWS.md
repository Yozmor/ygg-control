# ygg-control для Windows

Графическое окно на Direct2D: без браузерного движка, лёгкое по памяти и видеокарте. Общее описание и список экранов — в [README.md](../README.md).

## Установка

1. Нужен установленный [Yggdrasil для Windows](https://yggdrasil-network.github.io/installation-windows.html) (служба «Yggdrasil»).
2. Скачай `ygg_control.exe` из этой папки: кликни по файлу, потом на **Download raw file** (стрелка вниз справа). Положи его в постоянную папку, например `C:\Tools\ygg-control`.
3. Запусти. Windows попросит права администратора — соглашайся.

Пути панель берёт из настроек службы (`-useconffile`, `-logto`), а адрес управления — из `AdminListen` в конфиге, так что ничего настраивать не нужно.

Сторожа панель находит сама: он при каждом запуске записывает свой путь в `HKLM\SOFTWARE\Yozmor\ygg-watchdog`. Если не нашла, внизу окна есть «указать ygg_watchdog.exe…».

Адресная книга устройств хранится в `addressbook.txt` рядом с панелью.

## Управление

Команды слева выбираются мышью или стрелками **↑ ↓**. **Tab / Shift+Tab** переводит фокус по кругу: список команд → поля → списки → таблица экрана. Стрелки работают там, где сейчас фокус (он обведён рамкой).

| Клавиша | Что делает |
|---|---|
| **W** | открыть окно сторожа |
| **T** | проверка сторожем прямо сейчас |
| **Esc** | назад, к списку команд, или свернуть окно |

## Обновления

- **Панель.** На экране «Служба» → «Обновления» кнопка «Проверить» читает `PANEL_VERSION` в `windows/src/core.h` на GitHub. Панель проверяет это и сама при запуске. Если версия в репозитории новее, кнопка «Установить»:
  1. скачивает `windows/ygg_control.exe` и сверяет его git-отпечаток с репозиторием (обрезанный по дороге файл не пройдёт);
  2. запускает новую версию в режиме самопроверки (`ygg_control.exe --selftest`): она должна запуститься и назвать ту версию, что в исходнике;
  3. закрывает панель, заменяет файл и открывает её снова. Старая версия остаётся рядом как `ygg_control.exe.backup` и возвращается сама, если новая на месте не запустилась.
- **Yggdrasil.** Там же — проверка последнего релиза Yggdrasil и установка его штатным установщиком (`.msi`). Конфиг и ключ при этом не трогаются.

## Конфиг

Конфиг записывается в JSON, поэтому комментарии из файла пропадут. Yggdrasil читает JSON так же, как HJSON. Перед записью его проверяет сам `yggdrasil -normaliseconf`, старый файл остаётся рядом как `yggdrasil.conf.bak-ДАТА`, а новый записывается целиком или не записывается вовсе, даже если посреди записи пропадёт питание.

## Сборка

Скачай весь репозиторий (зелёная кнопка **Code → Download ZIP**), открой папку `windows` и запусти `build.bat`. Он соберёт `ygg_control.exe` через MinGW-w64 g++ или Visual Studio и откроет панель. Сторонних библиотек нет.

```
src/ygg_control.cpp   окно и экраны
src/core.h            Yggdrasil: пути, yggdrasilctl, конфиг, обновления, фоновый сбор данных (общий с ygg-watchdog)
src/util.h            процессы, пинг, DNS, порт, служба Windows, файлы (общий с ygg-watchdog)
src/ui.h              мини-библиотека отрисовки
src/json_lite.h       JSON
src/app.rc            иконка и фон
```

## Выпуск новой версии

1. Подними `PANEL_VERSION` в `windows/src/core.h` и собери `build.bat`.
2. Закоммить вместе `windows/src/core.h` и `windows/ygg_control.exe`.

Если номер подняли, а свежий exe забыли, панель это заметит и откажется ставить старый файл как новый.
